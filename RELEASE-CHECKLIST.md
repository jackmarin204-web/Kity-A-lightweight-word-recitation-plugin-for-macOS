# Public GitHub Release Checklist

- [ ] Create a public repository named `Kity`.
- [ ] Upload this project directory, excluding ignored files.
- [ ] Confirm no `.app`, `xcode-derived/`, `DerivedData/`, `xcuserdata/`, signing certificate, provisioning profile, or personal Notes content is present.
- [ ] Keep `LICENSES/LEXICON-NOTICE.md` if publishing the optional lexicon sources.
- [ ] Add a license before accepting outside contributions; no license is included yet, so copyright remains with the repository owner.
- [ ] Build locally, download the two system translation languages, and test in Apple Notes before publishing a binary release.
